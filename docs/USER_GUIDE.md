# RealBook Reader user guide

RealBook Reader is a free ebook reader that feels like a paper book. Your books stay on your own device: there is no account, and nothing is uploaded.

## Get the app

| Your device | What to use |
|---|---|
| **Android phone or tablet** | [Download the Android app (APK)](https://github.com/mrkukraty/realbook-reader/releases/download/v1.0.0/RealBook-Reader-1.0.0.apk) |
| **iPhone or iPad** | Open the web app: **https://realbook-reader.expo.app** |
| **Computer, or any other device** | Open the web app: **https://realbook-reader.expo.app** |

Newer versions, when there are any, appear on the [releases page](https://github.com/mrkukraty/realbook-reader/releases/latest).

### Install on Android

1. On your Android phone, tap the download link above. The file is about 105 MB.
2. When the download finishes, open the file `RealBook-Reader-1.0.0.apk`.
3. Android asks whether to allow your browser to install apps. Tap **Settings**, turn on **Allow from this source**, then go back.
4. Tap **Install**, then **Open**.

Android shows an "unknown source" warning for every app installed outside the Play Store. That is expected here.

To update later, download the newer APK and install it over the old one. Your library is kept.

### Use it on iPhone or iPad

There is no iPhone app to install, because Apple only allows installs through the App Store. Use the web app instead:

1. Open **https://realbook-reader.expo.app** in **Safari**.
2. Tap the **Share** button, then **Add to Home Screen**.
3. Open RealBook from its new home screen icon. It works offline after the first visit.

The web app is an earlier version and has fewer features than the Android app. See [The web app](#the-web-app).

The rest of this guide describes the Android app, except where it says otherwise.

## Add your books

1. First get the book file onto your phone, for example by downloading it or copying it from a computer.
2. In the library, tap the **+** button at the top right.
3. Pick one or more files. You can select several at once.
4. Wait for the import to finish. A summary tells you what was added.

Good to know:

- The app keeps its own copy of each book, so you can delete the original file afterwards.
- A book you already have is not added twice.
- If one file fails, the others are still imported, and the summary says what went wrong.
- Books protected by DRM, such as most books bought from Kindle or Adobe stores, cannot be opened.

## The library

The library is the first screen. Each book shows its cover, title, author, file type, size and how far you have read.

| To do this | Do this |
|---|---|
| Open a book | Tap it |
| See more options for a book | Press and hold it |
| Find a book | Type in the search box (title, author or file name) |
| Change the order | Tap the **Sort** chip to step through: recent, added, title, author, progress, size |
| Show only favourites | Tap the **Favorites** chip |
| Make a collection | Tap **New collection** and give it a name |
| Rename or delete a collection | Press and hold the collection's chip |
| Open settings | Tap the gear at the top right |

Pressing and holding a book gives you:

- **Open**
- **Details & edit**: change the title, author, publisher, date, language and description, and choose which collections the book belongs to
- **Add to favorites** or **Remove from favorites**
- **Remove from library**: deletes the book and its bookmarks, highlights and reading position from the app

## Reading a book

| To do this | Do this |
|---|---|
| Next page | Tap the right side of the page, or swipe left |
| Previous page | Tap the left side of the page, or swipe right |
| Show or hide the toolbars | Tap the middle of the page |
| Jump anywhere in the book | Drag the bar at the bottom |
| Go to a page or a percentage | Tap the progress text at the bottom |
| Go back to the library | Tap the arrow at the top left |

The app remembers where you stopped in every book.

**Top toolbar**, left to right:

| Button | What it does |
|---|---|
| Arrow | Back to the library |
| List | Contents (chapters) |
| Magnifier | Search inside the book |
| Wand | Your highlights and notes (text books only) |
| Bookmark | Add or remove a bookmark on this page |
| Stack | All your bookmarks in this book |
| **T** | Appearance: theme, fonts and comfort settings |

**Bottom toolbar**, left to right: previous page, focus timer, read aloud, progress, next page.

On phones held upright you see one page. On tablets and in landscape you see two pages side by side. You can change this in Settings under **Layout**.

## Change how the page looks

Tap the **T** button in the reader.

**Themes**

| Theme | Look |
|---|---|
| Kindle | Flat e-reader page that fills the screen; pages change instantly |
| Classic Ivory | Cream paper |
| Antique Parchment | Warm, aged paper |
| Clean E-Ink | Grey-white with black text |
| Sepia | Brown-toned paper |
| Night Reading | Dark page with soft light text |
| Pure Black | Black page, best for OLED screens in the dark |

**Comfort**

- **Dim page**: darkens the page beyond your screen's lowest brightness.
- **Warm light**: adds an orange tint that is easier on the eyes at night.
- **Keep screen awake while reading**: stops the screen turning off.

**Text** (text books, and PDFs in Text view)

- **Font**: more than 20 fonts in four groups: Classic, Modern, Handwritten and Typewriter.
- **Font size**: 12 to 40. You can also pinch the page with two fingers to change it.
- **Line height**, **Paragraph spacing**, **Margins** and **Alignment** (left or justified).

## PDFs and comics

**Zoom.** Pinch outward on a PDF or comic page to zoom in. Drag to move around. Pinch back in, double-tap, or tap the button at the top right to return to page turning.

**Read a PDF as text.** A PDF normally shows the printed page, so its font cannot be changed. To change that:

1. Open the PDF and tap the **T** button.
2. Under **Read this PDF as**, choose **Text**.

The words now flow like an ordinary book, and every font and size setting applies. Page numbers, bookmarks and "go to page" still refer to the original PDF pages. Pictures and complex layouts are only shown in **Pages** view, and scanned PDFs have no text to show.

**PDF page colours.** In Pages view, **Page colours** can be **Theme** (the page is tinted to match your theme, including dark themes) or **Original** (as printed).

**Comics** (CBZ files) are pictures, so they cannot be searched, highlighted or read aloud.

## Read aloud

The app can read a book to you and turn the pages itself.

1. Open a book and tap the middle of the page to show the toolbars.
2. Tap the **speaker** button in the bottom toolbar.

A small player appears over the page:

| Button | What it does |
|---|---|
| Pause / Play | Pause and continue |
| Stop | Stop reading aloud |
| Sliders | Choose the speed and the voice |

**Voice and accent.** With **Auto**, each passage is read in its own language, in your own accent. The accent comes from your phone's language and region, so a phone set to India reads English in Indian English, and one set to the UK reads it in British English. Hindi, Tamil, Arabic, Chinese, Russian and many other languages are recognised by their writing.

You can also pick one language and accent for everything, and choose between the individual voices your phone offers for it.

**Speed** goes from 0.5× to 2×.

Good to know:

- The voices are the ones installed on your phone. To add more, open your phone's **Settings**, search for **Text-to-speech**, and install voice data for the language you want.
- It works for text books and PDFs. Pages that are only pictures are skipped.
- If you turn the page yourself, reading continues from the new page.
- After a pause, the last sentence or two is repeated.
- It reads only while the app is open on screen, not with the phone locked.

## Focus timer and reading stats

Tap the **timer** button in the bottom toolbar.

**Focus timer**

1. Tap **10**, **15**, **25** or **45** minutes to start a session.
2. A small countdown stays on the page while you read. Tap it to pause, resume or end the session.
3. When the time is up, the phone buzzes and shows how many pages you read.

**Reading stats** are shown in the same panel and in Settings:

- **Today**: how long you have read today
- **Pages today**
- **Streak**: days in a row with at least one minute of reading
- A bar for each of the last 7 days

Once you have read for a few minutes, the app also estimates the time left in the book at your pace.

Reading time is only counted while the book is open and you are turning pages.

## Bookmarks, highlights and notes

**Bookmarks**

- Tap the **bookmark** button at the top to mark the current page. Tap it again to remove the mark.
- Tap the **stack** button to see all bookmarks in the book and jump to one.

**Highlights and notes** (text books)

1. Press and hold a word, then drag the handles to select a passage.
2. Tap a colour to highlight it, or the pencil to highlight it and write a note.
3. The copy button copies the passage instead.

Tap a highlight in the text to read or edit its note, or to delete it. The **wand** button at the top lists every highlight and note in the book.

**Search.** Tap the **magnifier**, type at least two letters, and tap a result to go there.

## Settings

Open Settings from the gear in the library.

| Section | What you can change |
|---|---|
| Theme | The colour theme of the whole app |
| Reading status | Your reading time, pages and streak |
| Comfort | Dim page, warm light, keep screen awake |
| Typography | Font, size, spacing, margins, alignment |
| Layout | One page, two pages, or automatic |
| Page turning | Turn the page animation on or off; its speed and shadow strength |
| Performance | **Lightweight** for older phones, **Balanced**, or **High quality** |
| Storage | How much space your books use; **Clear page cache** frees space without touching your books |
| Formats | The file types the app can open |

**Reset all settings** at the bottom returns everything to the defaults. Your books are not affected.

## The web app

**https://realbook-reader.expo.app** works in the browser on iPhone, iPad, Android and computers.

- **iPhone and iPad:** open it in Safari, tap **Share**, then **Add to Home Screen**.
- **Android:** open it in Chrome, tap the menu, then **Install app** or **Add to Home screen**.
- **Computer:** just open the link. You can also drag book files onto the page.

After the first visit it works without an internet connection.

It has the library, the page-turn animation, favourites, collections, bookmarks, highlights and reading progress.

It does **not** have read aloud, the focus timer, reading stats or the PDF Text view. Those are in the Android app only.

Your books are stored inside the browser. **If you clear the browser's site data or history for this site, your library is deleted.** Keep the original files of books you care about.

## Supported book files

| File type | Works? | Notes |
|---|---|---|
| EPUB | Yes | Not if it is DRM-protected |
| PDF | Yes | Up to 120 MB. Password-protected PDFs are refused |
| Text (.txt) | Yes | |
| Markdown (.md) | Yes | |
| HTML | Yes | |
| FictionBook (.fb2, .fb2.zip) | Yes | |
| Word (.docx) | Partly | Text, headings, bold and italic only; no tables or pictures |
| Rich Text (.rtf) | Yes | Text and simple formatting |
| Comics (.cbz) | Yes | Up to 150 MB |
| Kindle (.mobi, .azw, .azw3) | No | Convert to EPUB with [Calibre](https://calibre-ebook.com) |
| Comics (.cbr) | No | Convert to CBZ with Calibre or 7-Zip |
| DjVu | No | Convert to PDF |

The app never removes DRM. Use only books you have the right to read.

## Your data and privacy

- Books, reading positions, bookmarks, highlights, notes and reading stats are stored only on your device.
- There is no account, no advertising and no tracking.
- The app does not use the internet for your books. The only time it goes online is when you tap a web link inside a book, and it asks first.
- Read aloud uses the voices built into your phone.

Because everything is on your device, **uninstalling the app deletes your library**. Your original book files elsewhere on the phone are not touched.

## Problems and fixes

| Problem | What to try |
|---|---|
| Android will not install the APK | Allow installs from your browser when asked (see [Install on Android](#install-on-android)), and check you have about 300 MB free |
| A book will not import | Check the file type in the table above. Store-bought books usually have DRM and cannot be opened |
| Read aloud is silent | Turn up the media volume. Check that your phone has text-to-speech voices installed |
| Read aloud uses the wrong language or accent | Tap the sliders button on the player and choose the voice yourself |
| A PDF shows a message about no selectable text | It is a scanned PDF. Use Pages view; it cannot be re-flowed, searched or read aloud |
| Page turns are slow or jerky | In Settings, set **Performance** to **Lightweight**, or turn off the page-turn animation |
| The app uses a lot of storage | In Settings, tap **Clear page cache** |
| My library is gone in the web app | The browser's site data was cleared. Import the books again |

This is a first release and has had limited testing on real devices. If something does not work, please [report it](https://github.com/mrkukraty/realbook-reader/issues).
