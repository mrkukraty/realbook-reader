# RealBook Reader

A local-first ebook reader built with React, TypeScript and Vite. It runs in the browser (installable as a PWA, works offline) and as a Windows desktop app (Tauri 2). Your books never leave your device.

## Get the app

| Your device | What to use |
| --- | --- |
| **Android** | [Download the Android app (APK)](https://github.com/mrkukraty/realbook-reader/releases/download/v1.0.0/RealBook-Reader-1.0.0.apk), open the file and allow the install |
| **iPhone / iPad** | Open the web app at **https://realbook-reader.expo.app** in Safari, then Share › Add to Home Screen |
| **Computer or any browser** | **https://realbook-reader.expo.app** |

**[Read the user guide](docs/USER_GUIDE.md)** for installing, adding books, read aloud, the focus timer, PDFs and everything else.

The Android app (in [`mobile/`](mobile/README.md)) has the most features: read aloud in any language and accent, a focus timer, reading stats, a text view for PDFs and pinch zoom. The web app does not have those yet. All releases are on the [releases page](https://github.com/mrkukraty/realbook-reader/releases).

## Features

- Import books by file picker or drag and drop; duplicate detection by SHA-256 hash.
- Library with covers, favorites, collections, reading progress, bookmarks and highlights.
- Realistic page-turn animation (custom CSS 3D engine) for paged reading.
- Reflowable formats are parsed and sanitized in-app; PDF and CBZ are rendered page by page.
- Installable PWA with offline precache of the app shell and the pdf.js worker.
- Windows desktop build (NSIS and MSI installers) storing data in a normal folder on disk.

## Supported formats

| Format | Status | Notes |
| --- | --- | --- |
| EPUB | Supported | In-app parser (JSZip). DRM-protected EPUBs cannot be opened. |
| PDF | Supported | pdf.js. Text layer only if the PDF contains real text; scans have no text/search. |
| TXT | Supported | |
| HTML | Supported | Sanitized (DOMPurify). Scripts and event handlers are removed. |
| Markdown | Supported | Rendered with marked, then sanitized. |
| FB2 | Supported | In-app parser. |
| DOCX | Supported | Converted with mammoth; complex layout (columns, text boxes, some tables) is simplified. |
| RTF | Supported | Basic RTF parser; text and simple formatting only. |
| CBZ | Supported | Image-only comic archive; no text layer. |
| CBR | Not supported in-app | Convert to CBZ (see below). |
| MOBI / AZW / AZW3 | Not supported in-app | Convert to EPUB with Calibre. |
| DJVU | Not supported in-app | Convert to PDF with DjVuLibre. |

### Converting unsupported formats

- MOBI / AZW / AZW3 to EPUB: `ebook-convert book.azw3 book.epub` (Calibre).
- CBR to CBZ: extract with 7-Zip (`7z x book.cbr -obook`) and re-zip the images (`7z a -tzip book.cbz .\book\*`), or `ebook-convert book.cbr book.cbz`.
- DJVU to PDF: `ddjvu -format=pdf book.djvu book.pdf` (DjVuLibre).

DRM: RealBook Reader does not remove or circumvent DRM. Books protected by DRM (for example most store-bought Kindle or Adobe ADEPT files) cannot be opened. Use only files you are entitled to read.

## Quick start

```
npm install
npm run dev        # http://localhost:5173
npm run build      # typecheck + production build into dist/ (incl. service worker + manifest)
npm run preview    # serve dist/
npm test           # vitest (jsdom)
```

The service worker is generated by `vite-plugin-pwa` at build time and registered by `registerPWA()` from `src/app/pwa.ts` (must be called from `src/main.tsx`). It is skipped inside the desktop app.

## Desktop app (Tauri 2)

Prerequisites (Windows):

1. Rust via [rustup](https://rustup.rs) (stable, MSVC toolchain).
2. Microsoft C++ Build Tools (Visual Studio Build Tools, "Desktop development with C++" workload).
3. WebView2 runtime (preinstalled on Windows 11; installer bootstraps it otherwise).
4. Node.js and `npm install`.

```
npm run desktop:icons   # (optional) regenerate icons in public/ and src-tauri/icons/
npm run tauri:dev       # dev window against the Vite dev server
npm run tauri:build     # release build + installers
```

Installers are written to `src-tauri/target/release/bundle/nsis/` (`RealBook Reader_1.0.0_x64-setup.exe`) and `src-tauri/target/release/bundle/msi/` (`RealBook Reader_1.0.0_x64_en-US.msi`). The first build downloads and compiles many crates and can take several minutes.

Desktop data lives in `%APPDATA%\RealBook Reader\` (`library.json` plus `books\<id>.bin`). The app can reveal this folder (`open_data_dir`).

## Architecture (short)

- **Format adapters** (`src/formats/**`) turn a file into a `ReflowDocument` (sanitized HTML sections) or a `FixedDocument` (pages rendered on demand).
- **StorageAdapter** (`src/storage/StorageAdapter.ts`) is the persistence contract. `BrowserStorage` uses IndexedDB (Dexie); `DesktopStorage` keeps one `library.json` (atomic writes) and per-book files through Rust commands.
- **PageFlipEngine** is an abstraction over the page-turn animation. The shipped engine is a custom CSS 3D implementation rather than StPageFlip: it must handle variable-height reflowed content, arbitrary page renderers (canvas/DOM) and cancellation, runs without a third-party canvas layer, and is covered by our own tests.
- **Desktop shell** (`src-tauri/`) exposes a handful of narrow commands; no generic filesystem access.

See `docs/ARCHITECTURE.md` and `docs/SECURITY.md`.

## Privacy and security

Everything is local: no accounts, analytics or network calls for book content. Imported markup is sanitized, a strict CSP is enforced in the desktop app, and Tauri permissions are limited to the core plugin and a native open dialog. Details in `docs/SECURITY.md`.

## Storage notes

- Browser: books, covers and progress are stored in IndexedDB for the site origin. **Clearing site data / cookies for the site deletes your library.** Browsers may also evict data under storage pressure unless persistent storage is granted. Back up files you care about.
- Desktop: data is a plain folder (see above). Uninstalling the app does not necessarily remove it.

## Browser support and limitations

Targets current Chromium-based browsers, Firefox and Safari (ES2022, IndexedDB, Blob, CSS 3D transforms). The PWA install prompt and offline mode depend on the browser; the service worker requires HTTPS or localhost.

## Testing

`npm test` runs vitest with jsdom and `fake-indexeddb`. `tests/desktop/` tests `DesktopStorage` against an in-memory fake of the Rust backend. The Rust code has a unit test for ID validation (`cargo test` in `src-tauri`). Real windowing, the native dialog and installers can only be checked by running the desktop app.

## Known limitations

- CBR, MOBI, AZW/AZW3 and DJVU are not readable in-app.
- DRM-protected files are not supported.
- Scanned PDFs and comics have no text search or highlights.
- DOCX/RTF fidelity is approximate.
- Desktop: Windows is the only bundle target configured.
